Requires Plugins: woocommerce
Stable tag: 0.1.0

Store data and business logic for the Priniti Foods storefront.

== Description ==

* Product fields from the design's data model (highlights, ingredients, nutrition, storage, FAQs, pack size,
  internal data-quality notes that are never rendered). See includes/meta-keys.php.
* Product category flags (hide-when-empty, origin, cover product).
* "Pack size" shown on cart lines and order items for simple products.

Presentation lives in the "priniti" theme. Planned modules (later phases): product field editing UI,
contact form handler, homepage merchandising settings, order-tracking lookup.
